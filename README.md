# URL Shortener

A modern URL shortening application built with Next.js that allows users to create shortened URLs for easier sharing.

## Features

- Create shortened URLs from long links
- Modern, responsive UI with a gradient background
- Copy shortened URLs to clipboard with a single click
- Custom footer with GitHub link

## Tech Stack

- **Frontend**: Next.js, React, TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Shadcn UI

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mxyxyz9/url-shorter.git
   cd url-shorter
   ```

2. Install dependencies:
   ```bash
   cd fronend
   npm install
   # or
   pnpm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   # or
   pnpm dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.
